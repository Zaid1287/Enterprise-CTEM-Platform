  • Invitation system (pre-registration email tokens)

  • Drizzle ORM — schema definition, migrations, query builder
  • drizzle-zod — schema → Zod validation schemas
  • 30+ tables, all with tenantId column
  • Row-Level Security (RLS) on every tenant-scoped table
  • PostgreSQL tsvector full-text search (assets + findings)
  • Immutable audit log (PostgreSQL BEFORE UPDATE/DELETE trigger)
  • Orval codegen — OpenAPI → React Query hooks + Zod schemas
  • Stripe billing schema (packages, subscriptions, tiers)
  • All queries: WHERE tenant_id = JWT.tenantId
⚙️ Background Workers & Queue
  • beatScheduler — polls every 60 s (not hourly — critical)
  • Dispatches asset-frequency scans (hourly/daily/weekly/monthly)
  • Dispatches schedule-based pipeline triggers via nextRunAt
  • BullMQ job queue (Redis) with in-memory FIFO fallback
  • MAX_CONCURRENT_SCANS = 5 · MAX_PARALLEL_ASSETS = 3
  • Stuck-job watchdog (10 min timeout → auto-fail)
  • Alert worker — async notification dispatch queue
  • Startup scan recovery — resumes scans interrupted by restart
  • finalizeScannedAssets() — risk recalculation post-scan
  • Queue Monitor page (super_admin, BullMQ metrics)
2 Data Collection Engines
🔬 Active Scan Pipeline — 5-Phase Architecture
Phase 1 — Passive Recon (parallel)
WHOISDNS (A/AAAA/MX/NS/TXT/SOA/CNAME/SRV) SPF full policy parseDMARC (adkim/aspf/pct/rua) DKIM selector probingcrt.sh CT logs ASN lookup (ip-api.com)Shodan InternetDB VirusTotal enrichment
Phase 2 — Network & TLS (parallel)
Nmap -sT → Naabu → Masscan (fallback chain) 26 dangerous port categories SSL/TLS cert analysis (tls.connect) HTTP probing (status, title, headers, HSTS)
Phase 3 — Web Fingerprinting (parallel)
Technology Detection (400+ signatures) Puppeteer Screenshots (homepage, login, admin) Directory Fuzzing (BFS depth-3, 2000 endpoints max)
Phase 4 — Deep Analysis (parallel)
Nuclei (40+ templates) Secrets Hunting (trufflehog-style) JS Analyzer (API keys in JS bundles) Cloud Recon (S3/GCS/Azure permutation) Parameter Discovery (injectable params)
Phase 5 — Finalization (sequential)
EXP-PORT findings (26 dangerous ports → critical) EPSS batch enrichment (100 CVEs/req) KEV enrichment (CISA, 24h cache) Deduplication (CVE ID + assetId) Finding INSERT to DB finalizeScannedAssets() → risk recalculation dispatchNotifications → alert rules → channels
